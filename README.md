## Technical Architecture

- **Framework:** Next.js 15 (App Router, Turbopack enabled)
- **UI & Runtime:** React 19, TypeScript (strict mode)
- **Styling:** Tailwind CSS v4 with custom dark editorial theme
- **Typography:** PP Frama (Black Italic display, Meta technical accents) & Inter body
- **Motion & Physics:** Lenis smooth scrolling, RAF-synchronized scroll reveals, interactive pointer physics

## Getting Started

### Prerequisites

- Node.js 20.x or higher
- npm 10.x or higher

### Installation

```bash
# Clone the repository
git clone https://github.com/StylixXD/Portfolio.git
cd Portfolio

# Install dependencies
npm install
```

### Local Development

```bash
# Start development server on localhost:3000
npm run dev
```

### Production Build

```bash
# Compile and optimize for production
npm run build

# Preview production build locally
npm run start
```

## Deployment (Vercel)

This repository includes a production-ready `vercel.json` configuration for zero-config deployments.

1. Push this repository to GitHub at `StylixXD/Portfolio`.
2. In the [Vercel Dashboard](https://vercel.com/new), select **Import Git Repository**.
3. Choose `StylixXD/Portfolio`.
4. Set the project name to `stylixdev` to deploy to `https://stylixdev.vercel.app`.
5. Deploy.
