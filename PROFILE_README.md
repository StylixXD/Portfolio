### What I Build

- **High-Concurrency Bots & Gateways:** Multi-threaded bot clusters, event-driven socket handling, MTProto session multiplexing, and custom token rotation under aggressive rate limits.
- **Security & Session Tooling:** Proactive Discord moderation bots, token integrity guards, audit pipelines, and authorization flow analysis.
- **Protocol & Auth Automation:** Reverse-engineered OAuth2 pipelines, Microsoft Live / Xbox token validation engines, and distributed proxy rotation meshes.
- **Native & Systems Engineering:** Android utilities leveraging scoped storage & SAF, low-level WinAPI hooks, process memory inspection, and local data organizers.
- **Headless Scraping & Automation:** Resilient web automation with custom fingerprint evasion, dynamic DOM parsing, and pipeline orchestration.
